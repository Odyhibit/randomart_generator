What am I looking at?

When you run ssh-keygen -lv on a key, it hashes the key and then walks a virtual “bishop” chess piece around a 17×9 grid, using two bits from the hash at a time to decide which diagonal direction to move. Cells get a character based on how many times the bishop visits them, the start is marked S, and where the walk ends is marked E. The result is a small picture that's much easier for a human to eyeball-compare than a long string of hex — two keys that produce visibly different art are obviously different keys.

This algorithm comes from OpenSSH (not OpenSSL, which has no randomart feature) — it implements the “drunken bishop” hash-visualization technique described by Adrian Perrig and Dawn Song's paper “Hash Visualization: A New Technique to Improve Real-World Security” (1999). See docs/algorithm.md for the full algorithm write-up.
